Nexora Dark 1.0.3
=================

Dark phpBB style by Spiderpiggy, based on prosilver and Lucid Lime by Melvin García.

Requirements: phpBB 3.3.19 with the matching prosilver parent style installed.
Installation: copy nexora_dark/ into styles/, then install Nexora Dark in the ACP.
Updating: overwrite the existing style files, purge the phpBB cache and refresh the browser cache.

Member-list profile headings use phpBB's READ_PROFILE language key.
The extra fixed Dutch FAQ introduction has been removed.
No additional language files or extensions are required for these changes.

See README.md and CHANGELOG.md in this directory for design details and version history.
